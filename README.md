A program that writes exactly one emoji to `/output/entry.txt`: 😇 Smiling Face with Halo. One emoji, nothing else: no words, no caption, no explanation. The pick: a smiling face, so it triggers a smile directly, with a halo that adds innocence, kindness and gentle goodness. Warm at first glance, universal, appropriate from a stranger, and deliberately chosen rather than the default smiley. It is also one of the least duplicated warm picks in a field of 1,077 entries, where byte-identical entries share one rate and the earliest receipt places first.

## Run it

```sh
node main.ts
```

It writes `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (or `/output`), UTF-8, one emoji, no trailing newline. Node 22 standard library only, no network, fully deterministic: run it twice and the output is byte-identical.
